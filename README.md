# Турецкий работает как часы

Лендинг-гайд по турецкой грамматике в стиле сторителлинга + витрина платформы **Alterna** (A0 → C1).

Пять глав: регулярность правил, агглютинация, порядок слов (SOV), отсутствие рода и артиклей, гармония гласных.

## Интерактив
- конструктор слова «поезд» (`ev → evlerimdeki`)
- перестановка глагола в конец (FLIP-анимация)
- мини-игра «поймай окончание» (-ler / -lar)
- квиз на три вопроса
- кольцевая диаграмма состава, бары регулярности, дорожка уровней
- физика в футере (Matter.js)

## Стек
Статика: HTML + CSS + ванильный JS. Без сборки.

```
index.html
css/styles.css
js/app.js
media/img/     скриншоты платформы
media/video/   записи экрана
```
